## Preservation and release boundary

M1.01 does not remove a user function. The three Angular screens remain required parity surfaces. Future source corrections should be paired with their contract and tests; a missing deployed consumer or rewrite rule is an explicit pre-cutover gate, not an assumption that the legacy flow can be retired.

This matrix is a code inventory and target map. It does not certify real Meta permissions, production routing, Suite4 identity, webhook subscriptions, physical schema, or Hostinger behavior.
