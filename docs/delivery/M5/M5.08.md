## Boundaries

The application migration adds only the central checkpoint table at schema v25 after M5.06 v24. Destination `MetaConnectedPages`, `MetaConnectedNumbers` and `MetaAssetAutomationConfigs` DDL is a disposable test fixture only; the application does not create or alter enterprise destination tables. The focused harness explicitly injects `DurableLegacyProjectionJobScheduler` to verify atomic `PROJECTION_RECONCILE` intent with outbox events; default `JobsModule` composition leaves it disabled while the handler and `configuredLegacyProjectionRuntime()` remain absent because exact destination DDL, mapping/catalog provisioning, credentials and deployed consumer behavior are **Not confirmed**. Projection replay and rebuild scheduling are deferred until a matching runtime is reviewed. The source adapter selects metadata, allowlisted verified grants and opaque central references only. No destination write is enabled by the default application composition.

No provider operation, real tenant replication, PHP equivalence, production migration, or rollout was performed. See [ADR-021](../../meta-v2/adrs/ADR-021-m5-08-legacy-projection.md), [D-M5-07](decisions.md) and the [focused harness](../../../tools/m5-08/README.md).
