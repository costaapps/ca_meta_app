## Boundaries

The application migration adds only the central checkpoint table; its v22 number is provisional on this branch and must be reindexed to v25 after M5.06 and the other planned M5 migrations are integrated. Destination `MetaConnectedPages`, `MetaConnectedNumbers` and `MetaAssetAutomationConfigs` DDL is a disposable test fixture only; the application does not create or alter enterprise destination tables. Normal `JobsModule` composition now persists `PROJECTION_RECONCILE` intent atomically with outbox events, while the handler and `configuredLegacyProjectionRuntime()` remain absent because exact destination DDL, mapping/catalog provisioning, credentials and deployed consumer behavior are **Not confirmed**. The source adapter selects metadata, allowlisted verified grants and opaque central references only. No destination write is enabled by this package.

No provider operation, real tenant replication, PHP equivalence, production migration, or rollout was performed. See [ADR-021](../../meta-v2/adrs/ADR-021-m5-08-legacy-projection.md), [D-M5-06](decisions.md) and the [focused harness](../../../tools/m5-08/README.md).
