## Boundaries

The application migration adds only the central checkpoint table; its v22 number is provisional on this branch and must be reindexed to v25 after M5.06 and the other planned M5 migrations are integrated. Destination `MetaConnectedPages` DDL is a disposable test fixture only; the application does not create or alter enterprise destination tables. `configuredLegacyProjectionRuntime()` remains empty because exact destination DDL, mapping/catalog provisioning, credentials and deployed consumer behavior are **Not confirmed**. The source adapter selects metadata and opaque central references only. The worker does not claim/retry projection jobs until a separately reviewed runtime composition installs a catalog/source handler.

No provider operation, real tenant replication, PHP equivalence, production migration, or rollout was performed. See [ADR-021](../../meta-v2/adrs/ADR-021-m5-08-legacy-projection.md), [D-M5-06](decisions.md) and the [focused harness](../../../tools/m5-08/README.md).
