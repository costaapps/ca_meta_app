# M4.09 / #51 — Instagram integration package

## Candidate status

The candidate keeps Instagram via Facebook Login as the baseline and preserves Instagram Login as a separate optional variant. It adds a variant-specific M4.03 saga adapter seam and a reproducible synthetic harness. The adapter is not registered in the runtime because the initial user-credential handle, vault enrollment, Instagram subscription provider and app-specific permission evidence are unavailable.

The official Meta-maintained Instagram collection, consulted 2026-11-10, documents a Facebook Login discovery example at `GET /me/accounts?fields=name,access_token,tasks,instagram_business_account`, including a Page token and a linked professional Instagram account. Its separate Instagram Login section lists different `instagram_business_*` permissions. These are public request examples, not proof of this app's grants or eligibility. References: [Instagram API collection](https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api), [Instagram Login folder](https://www.postman.com/meta/instagram/folder/1z5vxzu/instagram-api-with-instagram-login).

## Reproducible focused gate

Prerequisites: Node.js 24.x, npm 11.x, and root dependencies from `npm ci --ignore-scripts`.

```powershell
node tools/m4-09/run-focused-test.mjs
```

The harness compiles the Instagram adapter and focused test into `apps/api/.test-runs/m4-09-*`, executes the synthetic Node tests, and removes its unique output directory. It does not contact Meta or use a database. The implementing agent did not run tests/builds/typecheck. ## Acceptance and external limits

- **Locally covered:** exact auth variant; mapped persisted auth family; Page relation required only for Facebook Login; zero and partial discovery never become ready; all-or-nothing account persistence receipts; subscriptions require an active observation for the exact account set; reconciliation is read-only.
- **Not confirmed:** current app ID/config and Graph version; Login for Business exchange response and scopes; Instagram Login exchange/refresh; app grants and review; initial user-token handle and vault enrollment; professional-account eligibility; Page/account relationship under this app's authorization; token expiry/revocation observations; Instagram subscription endpoint/fields and webhook receipt; authorized message/comment behavior.
- **Not exercised:** real Meta or Sandbox account, message, comment, subscription or webhook.

The package is not externally certified and must remain unavailable until the gaps above are resolved. No production action or customer credential was used.
