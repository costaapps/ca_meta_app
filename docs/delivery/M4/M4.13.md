## Delivery in this candidate

- Added authenticated, CSRF-protected local disconnect routes. A shared authorization with multiple active verified assets cannot be disconnected broadly; callers must select one asset. Asset disconnect changes only the exact tenant/authorization/asset binding. It does not revoke a shared credential or alter subscriptions.
- Added flow/auth-pair checked reauthorization that uses a connection-bound idempotency value and links the new onboarding session to the prior authorization. The prior authorization remains intact until later verified provider evidence.
- Added a hash-only callback receipt contract and a raw-body lifecycle callback endpoint. The default verifier and target resolver fail closed. A verified deauthorization is scoped to one server-mapped authorization; a data-deletion callback creates a M3.10 `RECEIVED` request/tombstone and does not purge data.
- Added schema version 20 for the idempotent command ledger and callback receipts. External cleanup is persisted as `BLOCKED` with `PROVIDER_OFFBOARDING_NOT_CONFIRMED` until an adapter is reviewed.
- Added M4.13 OpenAPI operations and regenerated the package and M1.07 TypeScript contract outputs after integrating M4.12. Added synthetic tests, a focused compiler config, and a cleanup-safe harness.
