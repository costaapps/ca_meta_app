## Security and operational boundary

The Graph API version is read only from M4.01 configuration with `VERIFIED` evidence. Its present value is never assumed by this client. M3.08's UUID `assetId` binds tenant-scoped credential policy; a distinct server-resolved provider object ID binds the request path. The credential exists only inside the resolver callback and is sent as a Bearer header over verified HTTPS. Public IDs, `cUUID`, provider object IDs, correlation IDs and cursors are not authority or metric labels.

Each operation is checked against the exact enabled M4.01 capability before credential resolution. The client enforces separate connect/header/read/overall timeouts, size limits, bounded pagination, GET retry and local quota/concurrency ceilings. A provider usage hint may reduce a local budget but is not treated as a documented Meta quota. Mutation ambiguity requires reconciliation; callers must not automatically resubmit.

On 2026-11-06 the Meta-maintained [Instagram API](https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api), [WhatsApp Cloud API](https://www.postman.com/meta/whatsapp-business-platform/documentation/wlk6lh4/whatsapp-cloud-api) and [Embedded Signup](https://www.postman.com/meta/whatsapp-business-platform/documentation/du6gzjv/embedded-signup) Postman collections were reviewed as shape references for Bearer headers, Graph hosts/versioned paths, cursor paging and usage hints. Meta's [Graph API reference](https://developers.facebook.com/docs/graph-api/overview/) error, pagination and rate-limiting pages returned HTTP 429 during source review. Exact provider error taxonomy, HTTP-200 `{error}` response semantics, `Retry-After` and quota headers remain **Not confirmed**. The M4.02 fixtures are synthetic and do not verify Meta app review, scopes or account behavior.
