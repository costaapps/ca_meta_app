## Corrected smoke findings before the passing run

Earlier candidate runs exposed harness/topology issues before the passing result: on the local Compose v2.38.1 run, including a worker without a healthcheck in `up --wait` returned the diagnostic `worker has no healthcheck configured` even though the process was running; an `internal: true` edge network also left the configured web host binding inactive. The harness now waits on web/API healthchecks and checks worker state/startup logs separately; `edge` is host-connected while the database network remains internal. These corrections are in the reviewed candidate and ADR-006.
